# My Favorite Person ♡ — V9.2 (self-contained edition)

## How to open it
1. Unzip the file.
2. Double-click **`index.html`**.

That's all. Every picture, the piano music, the styles and the games are inside `index.html` itself, so it works on its own — no other files or folders are needed. It also works offline.

Click **YES ♡** to start the music and the tour. Press **♪ MUSIC** at any time to play or pause it.

## Put it on the internet (GitHub Pages, free)
1. Create a new public repository on GitHub (for example `my-favorite-person`).
2. Upload **`index.html`** to the top level of the repository (drag and drop works).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
5. After about a minute, the address appears at the top of the Pages page: `https://<your-username>.github.io/<repository-name>/`.

Anyone with the link can open it. The page asks search engines not to list it.

## Change the words
Open `index.html` in a text editor (Notepad, TextEdit, VS Code). Search for **`EDIT YOUR WORDS`**. The block below it holds:
- `notes` — the three secret notes, one per game.
- `collection` — the message after all three games are finished.
- `finalMessage` — the short card on the last scene.

Keep the quotation marks and commas. To remove a line, set it to `""`.

The two letters are in the `letterPaper` section of `index.html`.

## Games
Open **The Heart Arcade** from the menu (card 05). Each game unlocks a secret note:
- **Catch My Heart** — move the basket with a finger, mouse or the arrow keys; catch ten hearts.
- **Heart Match** — find the six pairs.
- **Find My Heart** — guide the heart through the maze with the arrow keys, a swipe, or the buttons.

After all three, the heart collection opens. **Skip the games** goes straight to the letter.

## If something looks wrong
- Use a current browser (Chrome, Edge, Safari, Firefox).
- Press F12 and open the Console to see any messages.
- A picture that can't be shown appears as a small labelled box, never a broken-image icon.
- The first screen's pictures are built in, so they appear even if the file is viewed in a limited preview.
