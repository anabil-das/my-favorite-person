# Changelog

## V9.2 — self-contained edition (this file)
- **Everything is inside `index.html`.** Previously the pictures, the music and the game scripts were separate files in an `assets/` folder. Some viewers and previews did not load those files, which left pictures blank and the games unable to start. Now the single file carries every picture, the music, the styles and all the scripts, so it works when opened on its own.
- The page is about 5.6 MB as one file. The music is the same 128 kbps recording as before.
- The satin bow on the letters was moved to the corner so it no longer covers the first words.
- Missing pictures show a labelled placeholder rather than a broken icon.
- The text of the games, notes, collection message and final card is in one block inside `index.html`, marked "EDIT YOUR WORDS".
- Unchanged: all three games, the notes, the final card, the letters, the kitten introduction, the museum, the red thread, the envelope and the music controls.
